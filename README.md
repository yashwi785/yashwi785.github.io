# Yashwi Rathi | Portfolio

Personal portfolio website of Yashwi Rathi, an AI & Data Science undergraduate (B.Tech CSE, JECRC University, Jaipur) and Python / full-stack developer.

## Features

- Responsive layout with a mobile navigation menu
- Light and dark theme toggle (remembers your choice)
- Typing effect in the hero section
- Scroll-reveal animations and animated stat counters
- Filterable project cards (CLI & Automation, AI, Backend)
- Contact form with client-side validation (opens the visitor's email app, no backend needed)

## Built with

HTML5, CSS3 and vanilla JavaScript. No frameworks or build step.

## Run locally

Open `index.html` in your browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy with GitHub Pages

1. Push this folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
